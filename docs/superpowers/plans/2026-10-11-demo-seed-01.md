# DEMO-SEED-01 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two protected Artisan commands — `demo:seed` and `demo:reset` — that build and atomically rebuild a fully fictional, isolated Pharm.D demonstration institution with cases in every reachable workflow state.

**Architecture:** Small single-purpose classes under `app/Demo/` (guard, dataset constants, acting-as helper, inventory, seeder, case scenarios, case builder, purger) behind two thin console commands. Every status change goes through the real `SubmitCase` / `ReturnCase` / `ApproveCase` / `ReopenCase` actions; the reset is one outer transaction around an explicit, schema-checked purge registry plus the full rebuild.

**Tech Stack:** Laravel 13, PHP 8.4, PHPUnit (class-based), SQLite in tests, PostgreSQL 17 in Docker/Railway.

**Spec:** `docs/superpowers/specs/2026-10-11-demo-seed-01-design.md`

## Global Constraints

- Commands refuse (non-zero exit, no writes) unless `config('demo.enabled') === true` and `config('demo.password')` is a string of ≥ 12 characters. `APP_ENV` is never consulted.
- `config/demo.php`: `'enabled' => (bool) env('DEMO_MODE', false)`, `'password' => env('DEMO_PASSWORD')`.
- Institution: slug `pharmalab-demo-college`, name `Pharmalab Demo College`, timezone `Asia/Kolkata`.
- Exact user allowlist: `admin@pharmalab-demo.test` (Demo Administrator, administrator), `faculty@pharmalab-demo.test` (Dr. Demo Preceptor, faculty), `student1@pharmalab-demo.test` (Priya Demo, student), `student2@pharmalab-demo.test` (Rahul Demo, student).
- Rotation `General Medicine Clerkship`: starts `2022-01-01`, ends `2032-12-31`, active.
- Targets: overall 6, Cardiology 2, Respiratory 2, Infectious Disease 2.
- The demo password is never printed, logged, or placed in an exception message; it is stored only through `User`'s `hashed` cast.
- `--force` on `demo:reset` skips only the confirmation prompt, never a safety check.
- Do not modify `docker/start.sh`, `DemoUsersSeeder`, `DatabaseSeeder` or any SIMS data.
- Failure messages, verbatim: `Demo seed refused: <reason> No demo data was changed.` · `Demo seed failed while <step>. No demo data was changed.` · `Demo reset refused: <reason> No data was changed.` · `Demo reset failed while deleting <label>. No data was changed.` · `Demo reset failed while rebuilding the demo dataset (<step>). No data was changed.`
- Tests follow repo conventions: `class X extends Tests\TestCase`, `use RefreshDatabase`, `public function test_snake_case(): void`, `$this->assertX()`. Only `Institution` and `User` have factories.
- PHP commands run through PowerShell on this machine (`php artisan test --filter=...`, `php vendor\bin\pint`, `php vendor\bin\phpstan.phar analyse`).

## Review Focus

1. **Demo user left authenticated after a failure** — if an action throws mid-scenario, `DemoActingAs` must still restore the previous (null) user; covered in Task 1 (`test_acting_as_restores_the_previous_user_even_when_the_step_throws`).
2. **Faculty edits a target count or a student edits a case during a live demo, then someone runs `demo:seed`** — seed must refuse on the changed target rather than silently overwrite, and leave edited cases alone; covered in Task 2 (`test_a_changed_target_count_makes_seed_refuse`) and Task 3 (`test_seed_does_not_repair_a_case_edited_during_a_demo`).
3. **A student creates an extra case (case 7) through the UI during a demo** — seed must not treat it as a conflict, and reset must remove it; covered in Task 3 (`test_an_extra_case_created_in_the_ui_does_not_block_seed`) and Task 5 (`test_reset_restores_cases_modified_or_added_during_a_demo`).
4. **A demo user logged in on a device when reset runs** — their `sessions` rows must be removed so the stale session cannot point at a deleted user id; covered in Task 4 (`test_purge_removes_sessions_and_password_reset_tokens_of_demo_users_only`).
5. **Reset run on an environment where the demo has never been seeded** — must simply seed (no prompt, no purge); covered in Task 5 (`test_reset_without_an_existing_demo_simply_seeds`).

```php
<?php

namespace App\Demo;

/**
 * Fails closed: demo commands only run where DEMO_MODE is explicitly on and a
 * usable DEMO_PASSWORD is set. APP_ENV is deliberately ignored — Railway
 * staging runs with APP_ENV=production.
 */
class DemoGuard
{
    public const MIN_PASSWORD_LENGTH = 12;

    public function password(): string
    {
        if (config('demo.enabled') !== true) {
            throw new DemoRefusedException('DEMO_MODE is not enabled. Set DEMO_MODE=true on this environment to allow demo commands.');
        }

        $password = config('demo.password');
        if (! is_string($password) || mb_strlen($password) < self::MIN_PASSWORD_LENGTH) {
            throw new DemoRefusedException('DEMO_PASSWORD must be set to at least 12 characters.');
        }

        return $password;
    }
}
```

`app/Demo/DemoActingAs.php`:

```php
<?php

namespace App\Demo;

use App\Models\User;
use Closure;
use Illuminate\Auth\SessionGuard;
use Illuminate\Support\Facades\Auth;

/**
 * An Artisan command starts with no authenticated user, so institution global
 * scopes are inactive. Each workflow step sets exactly one demo user and
 * restores whatever was there before, even when the step throws, so no
 * identity leaks between steps or scenarios.
 */
class DemoActingAs
{
    /**
     * @template TResult
     *
     * @param  Closure(): TResult  $step
     * @return TResult
     */
    public function run(User $user, Closure $step): mixed
    {
        /** @var SessionGuard $guard */
        $guard = Auth::guard();
        $previous = $guard->hasUser() ? $guard->user() : null;

        try {
            $guard->setUser($user);

            return $step();
        } finally {
            if ($previous === null) {
                $guard->forgetUser();
            } else {
                $guard->setUser($previous);
            }
        }
    }
}
```

```php
<?php

namespace App\Demo;

use App\Models\Institution;
use Illuminate\Support\Facades\DB;

/**
 * Read-only views of the demo institution, for summaries and the reset
 * confirmation. Uses the query builder so no auth-dependent scope applies.
 */
class DemoInventory
{
    public function institution(): ?Institution
    {
        return Institution::query()->where('slug', DemoDataset::INSTITUTION_SLUG)->first();
    }

    /** @return array{users: int, cases: int, case_versions: int, review_comments: int, audit_events: int} */
    public function counts(Institution $institution): array
    {
        $count = fn (string $table): int => DB::table($table)->where('institution_id', $institution->id)->count();

        return [
            'users' => $count('users'),
            'cases' => $count('clinical_cases'),
            'case_versions' => $count('case_versions'),
            'review_comments' => $count('case_review_comments'),
            'audit_events' => $count('audit_events'),
        ];
    }

    /** @return list<array{0: string, 1: int}> */
    public function summaryRows(Institution $institution): array
    {
        $rows = [];
        foreach ($this->counts($institution) as $label => $count) {
            $rows[] = [str_replace('_', ' ', $label), $count];
        }

        $byStatus = DB::table('clinical_cases')
            ->where('institution_id', $institution->id)
            ->selectRaw('status, count(*) as aggregate')
            ->groupBy('status')
            ->orderBy('status')
            ->pluck('aggregate', 'status');
        foreach ($byStatus as $status => $count) {
            $rows[] = ["cases: {$status}", (int) $count];
        }

        return $rows;
    }
}
```

```php
<?php

namespace App\Demo;

use App\Enums\UserStatus;
use App\Models\AcademicCohort;
use App\Models\ClinicalSite;
use App\Models\Department;
use App\Models\Institution;
use App\Models\Programme;
use App\Models\Rotation;
use App\Models\RotationAssignment;
use App\Models\RotationCaseTarget;
use App\Models\User;
use App\Models\Ward;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Support\Carbon;

/**
 * Builds the demo dataset. Creates only what is missing; any existing row
 * found by natural key must already match the dataset, otherwise seeding
 * stops with a DemoRefusedException. Existing records are never reassigned.
 *
 * Bootstrap lookups use exact identifiers with withoutGlobalScopes(), because
 * the command starts with no authenticated user.
 */
class DemoSeeder
{
    private string $step = 'starting';

    public function currentStep(): string
    {
        return $this->step;
    }

    public function seed(string $password): void
    {
        $this->step = 'the demo institution';
        $institution = $this->institution();

        $this->step = 'the demo accounts';
        $users = $this->users($institution, $password);

        $this->step = 'the academic structure';
        $rotation = $this->structure($institution);

        $this->step = 'the rotation assignments';
        $faculty = $users[DemoDataset::FACULTY];
        foreach ([DemoDataset::STUDENT1, DemoDataset::STUDENT2] as $email) {
            $this->assignment($institution, $rotation, $users[$email], $faculty);
        }

        $this->step = 'the rotation case targets';
        foreach (DemoDataset::targets() as $target) {
            $this->ensure(
                RotationCaseTarget::class, $institution,
                ['rotation_id' => $rotation->id, 'category' => $target['category']],
                ['target_count' => $target['target_count']],
                ['created_by' => $faculty->id],
                'rotation case target '.($target['category'] ?? 'overall'),
            );
        }

        $this->step = 'finished';
    }

    private function institution(): Institution
    {
        $institution = Institution::query()->where('slug', DemoDataset::INSTITUTION_SLUG)->first();

        if ($institution === null) {
            return Institution::query()->create([
                'slug' => DemoDataset::INSTITUTION_SLUG,
                'name' => DemoDataset::INSTITUTION_NAME,
                'status' => 'active',
                'timezone' => DemoDataset::INSTITUTION_TIMEZONE,
            ]);
        }

        if ($institution->name !== DemoDataset::INSTITUTION_NAME) {
            throw new DemoRefusedException('institution '.DemoDataset::INSTITUTION_SLUG.' exists with a different name.');
        }

        return $institution;
    }

    /** @return array<string, User> */
    private function users(Institution $institution, string $password): array
    {
        $users = [];

        foreach (DemoDataset::users() as $email => $attributes) {
            $user = User::query()->withoutGlobalScopes()->where('email', $email)->first();

            if ($user === null) {
                $user = new User([
                    'institution_id' => $institution->id,
                    'name' => $attributes['name'],
                    'email' => $email,
                    'role' => $attributes['role'],
                    'status' => UserStatus::Active,
                ]);
                $user->email_verified_at = Carbon::now();
            } elseif ($user->institution_id !== $institution->id) {
                throw new DemoRefusedException("user {$email} belongs to another institution.");
            } elseif ($user->role !== $attributes['role']) {
                throw new DemoRefusedException("user {$email} does not have the expected {$attributes['role']->value} role.");
            }

            // Re-applied on every run so rotating DEMO_PASSWORD takes effect.
            // The hashed cast stores only the hash.
            $user->password = $password;
            $user->save();

            $users[$email] = $user;
        }

        return $users;
    }

    private function structure(Institution $institution): Rotation
    {
        $programme = $this->ensure(Programme::class, $institution,
            ['code' => DemoDataset::PROGRAMME_CODE],
            ['name' => DemoDataset::PROGRAMME_NAME],
            ['duration_years' => 6, 'status' => 'active'],
            'programme '.DemoDataset::PROGRAMME_CODE);

        $cohort = $this->ensure(AcademicCohort::class, $institution,
            ['programme_id' => $programme->id, 'name' => DemoDataset::COHORT_NAME],
            [],
            ['admission_year' => 2022, 'academic_year_label' => '2026–27', 'status' => 'active'],
            'academic cohort '.DemoDataset::COHORT_NAME);

        $site = $this->ensure(ClinicalSite::class, $institution,
            ['code' => DemoDataset::SITE_CODE],
            ['name' => DemoDataset::SITE_NAME],
            ['status' => 'active'],
            'clinical site '.DemoDataset::SITE_CODE);

        $department = $this->ensure(Department::class, $institution,
            ['clinical_site_id' => $site->id, 'name' => DemoDataset::DEPARTMENT_NAME],
            [],
            ['status' => 'active'],
            'department '.DemoDataset::DEPARTMENT_NAME);

        $ward = $this->ensure(Ward::class, $institution,
            ['code' => DemoDataset::WARD_CODE],
            ['clinical_site_id' => $site->id, 'department_id' => $department->id, 'name' => DemoDataset::WARD_NAME],
            ['status' => 'active'],
            'ward '.DemoDataset::WARD_CODE);

        return $this->ensure(Rotation::class, $institution,
            ['programme_id' => $programme->id, 'name' => DemoDataset::ROTATION_NAME],
            ['academic_cohort_id' => $cohort->id, 'clinical_site_id' => $site->id, 'department_id' => $department->id, 'ward_id' => $ward->id],
            ['starts_on' => DemoDataset::ROTATION_STARTS_ON, 'ends_on' => DemoDataset::ROTATION_ENDS_ON, 'status' => 'active'],
            'rotation '.DemoDataset::ROTATION_NAME);
    }

    private function assignment(Institution $institution, Rotation $rotation, User $student, User $faculty): RotationAssignment
    {
        return $this->ensure(RotationAssignment::class, $institution,
            ['rotation_id' => $rotation->id, 'student_id' => $student->id],
            ['primary_preceptor_id' => $faculty->id],
            ['status' => 'active'],
            "rotation assignment for {$student->email}");
    }

    /**
     * Find a row by natural key within the demo institution, or create it.
     * An existing row must match every $expected column exactly.
     *
     * @template TModel of Model
     *
     * @param  class-string<TModel>  $model
     * @param  array<string, mixed>  $key
     * @param  array<string, mixed>  $expected
     * @param  array<string, mixed>  $create
     * @return TModel
     */
    protected function ensure(string $model, Institution $institution, array $key, array $expected, array $create, string $label): Model
    {
        $existing = $model::query()->withoutGlobalScopes()
            ->where('institution_id', $institution->id)
            ->where($key)
            ->first();

        if ($existing === null) {
            return $model::query()->withoutGlobalScopes()->create([
                'institution_id' => $institution->id,
                ...$key,
                ...$expected,
                ...$create,
            ]);
        }

        foreach ($expected as $column => $value) {
            if ((string) $existing->getRawOriginal($column) !== (string) $value) {
                throw new DemoRefusedException("{$label} exists but its {$column} does not match the demo dataset.");
            }
        }

        return $existing;
    }
}
```

```php
namespace App\Console\Commands;

use App\Demo\DemoGuard;
use App\Demo\DemoInventory;

use Illuminate\Console\Command;

class DemoSeedCommand extends Command
{
    protected $signature = 'demo:seed';

    protected $description = 'Create any missing Pharmalab Demo College data and rotate the demo passwords (requires DEMO_MODE=true).';

    public function handle(DemoGuard $guard, DemoSeeder $seeder, DemoInventory $inventory): int
    {
        try {
            $password = $guard->password();
            DB::transaction(fn () => $seeder->seed($password));
        } catch (DemoRefusedException $e) {
            $this->error('Demo seed refused: '.$e->getMessage().' No demo data was changed.');

            return self::FAILURE;
        } catch (Throwable $e) {
            report($e);
            $this->error("Demo seed failed while seeding {$seeder->currentStep()}. No demo data was changed.");

            return self::FAILURE;
        }

        $institution = $inventory->institution();
        if ($institution !== null) {
            $this->info("Demo data ready: {$institution->name} ({$institution->slug})");
            $this->table(['Demo data', 'Count'], $inventory->summaryRows($institution));
        }

        return self::SUCCESS;
    }
}
```

```php
<?php

namespace App\Demo;

use App\Actions\ApproveCase;
use App\Actions\ReopenCase;

use App\Actions\SubmitCase;
use App\Enums\CaseFormVersion;
use App\Enums\CaseStatus;

use App\Models\CaseClinicalProfile;
use App\Models\CaseInvestigation;
use App\Models\CaseMedication;
use App\Models\CaseVital;
use App\Models\ClinicalCase;
use App\Models\RotationAssignment;
use App\Models\SoapNote;
use App\Models\User;

/**
 * Writes one scenario's student-authored content under the student's identity,
 * then drives every status change through the real workflow action under the
 * acting user's identity.
 *
 * @phpstan-import-type DemoScenario from DemoCaseScenarios
 * @phpstan-import-type DemoStep from DemoCaseScenarios
 */
class DemoCaseBuilder
{
    public function __construct(
        private readonly DemoActingAs $actingAs,
        private readonly SubmitCase $submit,
        private readonly ApproveCase $approve,
        private readonly ReturnCase $return,
        private readonly ReopenCase $reopen,
    ) {}

    /** @param DemoScenario $scenario */
    public function build(array $scenario, RotationAssignment $assignment, User $student, User $faculty): ClinicalCase
    {
        $case = $this->actingAs->run($student, fn (): ClinicalCase => $this->writeContent($scenario, $assignment, $student));

        foreach ($scenario['steps'] as $step) {
            $this->runStep($step, $case, $student, $faculty);
        }

        return $case;
    }

    /** @param DemoScenario $scenario */
    private function writeContent(array $scenario, RotationAssignment $assignment, User $student): ClinicalCase
    {
        $content = $scenario['content'];
        $owned = ['institution_id' => $assignment->institution_id];

        $case = ClinicalCase::query()->create([
            ...$owned,
            'student_id' => $student->id,
            'rotation_assignment_id' => $assignment->id,
            'case_number' => $scenario['case_number'],
            'status' => CaseStatus::Draft,
            'form_version' => CaseFormVersion::PharmdV1,
            'case_category' => $scenario['category'],
            ...$content['case'],
        ]);
        $forCase = [...$owned, 'clinical_case_id' => $case->id];

        CaseClinicalProfile::query()->create([...$forCase, ...$content['profile'], 'last_saved_by' => $student->id]);

        foreach ($content['vitals'] as $vital) {
            CaseVital::query()->create([...$forCase, ...$vital, 'recorded_by' => $student->id]);
        }
        foreach ($content['investigations'] as $investigation) {
            CaseInvestigation::query()->create([...$forCase, ...$investigation, 'recorded_by' => $student->id]);
        }
        foreach ($content['medications'] as $medication) {
            CaseMedication::query()->create([...$forCase, 'medication_context' => null, ...$medication, 'recorded_by' => $student->id]);
        }

        foreach ([ClinicalActivityType::Adr->value => $content['adr'], ClinicalActivityType::Counselling->value => $content['counselling']] as $type => $activity) {
            if ($activity !== null) {
                CaseClinicalActivity::query()->create([...$forCase, 'activity_type' => $type, ...$activity, 'recorded_by' => $student->id]);
            }
        }
        foreach ($content['interventions'] as $intervention) {
            CaseClinicalActivity::query()->create([...$forCase, 'activity_type' => ClinicalActivityType::Intervention->value, ...$intervention, 'recorded_by' => $student->id]);
        }

        if ($content['soap'] !== null) {
            SoapNote::query()->create([...$forCase, 'revision_number' => 1, ...$content['soap'], 'author_id' => $student->id, 'last_saved_by' => $student->id]);
        }

        return $case;
    }

    /** @param DemoStep $step */
    private function runStep(array $step, ClinicalCase $case, User $student, User $faculty): void
    {
        match ($step['action']) {
            'submit' => $this->actingAs->run($student, fn () => ($this->submit)($student, $case->fresh(), true)),
            'approve' => $this->actingAs->run($faculty, fn () => ($this->approve)($faculty, $case->fresh(), $step['summary'] ?? null, $step['comments'] ?? [])),
            'return' => $this->actingAs->run($faculty, fn () => ($this->return)($faculty, $case->fresh(), $step['reason'] ?? '', $step['comments'] ?? [])),
            'reopen' => $this->actingAs->run($faculty, fn () => ($this->reopen)($faculty, $case->fresh(), $step['reason'] ?? '')),
            'correct' => $this->actingAs->run($student, fn () => $this->correct($case, $step)),
        };
    }

    /** @param DemoStep $step */
    private function correct(ClinicalCase $case, array $step): void
    {
        foreach ($step['medications'] ?? [] as $genericName => $changes) {
            CaseMedication::query()
                ->where('clinical_case_id', $case->id)
                ->where('generic_name', $genericName)
                ->sole()
                ->update($changes);
        }

        if (isset($step['soap'])) {
            SoapNote::query()
                ->where('clinical_case_id', $case->id)
                ->orderByDesc('revision_number')
                ->firstOrFail()
                ->update($step['soap']);
        }
    }
}
```

```php
<?php

namespace App\Demo;

use App\Models\Institution;
use Illuminate\Database\QueryException;
use Illuminate\Support\Facades\DB;

/**
 * Deletes only the demo institution's rows, child before parent, through an
 * explicit registry reconciled against the migrations. Foreign keys stay
 * restrictive: a row outside the demo institution that references a demo row
 * makes its stage fail, and the caller's transaction rolls everything back.
 */
class DemoPurger
{
    /** Tables with no link to demo data. */
    public const EXEMPT_TABLES = ['migrations', 'cache', 'cache_locks', 'jobs', 'job_batches', 'failed_jobs'];

    /** Tables removed by an ON DELETE CASCADE foreign key: table => parent. */
    public const CASCADE_TABLES = ['passkeys' => 'users'];

    /** @return list<array{label: string, table: string, by: 'institution'|'user_ids'|'user_emails'|'id'}> */
    public static function registry(): array
    {
        return [
            ['label' => 'audit events', 'table' => 'audit_events', 'by' => 'institution'],
            ['label' => 'sync operations', 'table' => 'sync_operations', 'by' => 'institution'],
            ['label' => 'case review comments', 'table' => 'case_review_comments', 'by' => 'institution'],
            ['label' => 'case status transitions', 'table' => 'case_status_transitions', 'by' => 'institution'],
            ['label' => 'case versions', 'table' => 'case_versions', 'by' => 'institution'],
            ['label' => 'clinical activities', 'table' => 'case_clinical_activities', 'by' => 'institution'],
            ['label' => 'medications', 'table' => 'case_medications', 'by' => 'institution'],
            ['label' => 'investigations', 'table' => 'case_investigations', 'by' => 'institution'],
            ['label' => 'vitals', 'table' => 'case_vitals', 'by' => 'institution'],
            ['label' => 'clinical profiles', 'table' => 'case_clinical_profiles', 'by' => 'institution'],
            ['label' => 'SOAP notes', 'table' => 'soap_notes', 'by' => 'institution'],
            ['label' => 'case draft notes', 'table' => 'case_draft_notes', 'by' => 'institution'],
            ['label' => 'clinical cases', 'table' => 'clinical_cases', 'by' => 'institution'],
            ['label' => 'rotation case targets', 'table' => 'rotation_case_targets', 'by' => 'institution'],
            ['label' => 'rotation assignments', 'table' => 'rotation_assignments', 'by' => 'institution'],
            ['label' => 'rotations', 'table' => 'rotations', 'by' => 'institution'],
            ['label' => 'academic cohorts', 'table' => 'academic_cohorts', 'by' => 'institution'],
            ['label' => 'wards', 'table' => 'wards', 'by' => 'institution'],
            ['label' => 'departments', 'table' => 'departments', 'by' => 'institution'],
            ['label' => 'clinical sites', 'table' => 'clinical_sites', 'by' => 'institution'],
            ['label' => 'programmes', 'table' => 'programmes', 'by' => 'institution'],
            ['label' => 'demo user sessions', 'table' => 'sessions', 'by' => 'user_ids'],
            ['label' => 'demo password-reset tokens', 'table' => 'password_reset_tokens', 'by' => 'user_emails'],
            ['label' => 'demo users', 'table' => 'users', 'by' => 'institution'],
            ['label' => 'demo institution', 'table' => 'institutions', 'by' => 'id'],
        ];
    }

    /**
     * Every user in the demo institution must be on the allowlist (a subset is
     * fine, so a partly created demo can be recovered), and no allowlisted
     * email may be linked to another institution.
     */
    public function assertSafe(Institution $institution): void
    {
        if ($institution->slug !== DemoDataset::INSTITUTION_SLUG || $institution->name !== DemoDataset::INSTITUTION_NAME) {
            throw new DemoRefusedException('institution '.DemoDataset::INSTITUTION_SLUG.' exists with a different name.');
        }

        $allowlist = array_keys(DemoDataset::users());

        $unexpected = DB::table('users')->where('institution_id', $institution->id)->whereNotIn('email', $allowlist)->orderBy('email')->pluck('email')->all();
        if ($unexpected !== []) {
            throw new DemoRefusedException('the demo institution has users outside the demo allowlist: '.implode(', ', $unexpected).'.');
        }

        $elsewhere = DB::table('users')->whereIn('email', $allowlist)->where('institution_id', '!=', $institution->id)->orderBy('email')->pluck('email')->all();
        if ($elsewhere !== []) {
            throw new DemoRefusedException('demo accounts are linked to another institution: '.implode(', ', $elsewhere).'.');
        }
    }

    public function purge(Institution $institution): void
    {
        $users = DB::table('users')->where('institution_id', $institution->id);
        $userIds = (clone $users)->pluck('id')->all();
        $userEmails = (clone $users)->pluck('email')->all();

        foreach (self::registry() as $stage) {
            try {
                $query = DB::table($stage['table']);
                match ($stage['by']) {
                    'institution' => $query->where('institution_id', $institution->id)->delete(),
                    'user_ids' => $query->whereIn('user_id', $userIds)->delete(),
                    'user_emails' => $query->whereIn('email', $userEmails)->delete(),
                    'id' => $query->where('id', $institution->id)->delete(),
                };
            } catch (QueryException $e) {
                throw new DemoPurgeFailedException($stage['label'], $e);
            }
        }
    }
}
```

```php
<?php

namespace App\Console\Commands;

use App\Demo\DemoGuard;
use App\Demo\DemoInventory;
use App\Demo\DemoPurgeFailedException;
use App\Demo\DemoPurger;
use App\Demo\DemoRefusedException;
use App\Demo\DemoSeeder;
use Illuminate\Console\Command;
use Illuminate\Support\Facades\DB;
use Throwable;

class DemoResetCommand extends Command
{
    public const CONFIRMATION = 'Delete all of this demo data and rebuild it?';

    protected $signature = 'demo:reset {--force : Skip the confirmation prompt (safety checks still run)}';

    protected $description = 'Delete only the Pharmalab Demo College data and rebuild the full demo dataset (requires DEMO_MODE=true).';

    public function handle(DemoGuard $guard, DemoInventory $inventory, DemoPurger $purger, DemoSeeder $seeder): int
    {
        try {
            $password = $guard->password();
            $institution = $inventory->institution();
            if ($institution !== null) {
                $purger->assertSafe($institution);
            }
        } catch (DemoRefusedException $e) {
            $this->error('Demo reset refused: '.$e->getMessage().' No data was changed.');

            return self::FAILURE;
        }

        if ($institution !== null && ! $this->option('force')) {
            $this->line("Institution: {$institution->name} ({$institution->slug})");
            $this->table(['Will be removed', 'Count'], $inventory->summaryRows($institution));

            if (! $this->confirm(self::CONFIRMATION)) {
                $this->info('Demo reset cancelled. No data was changed.');

                return self::SUCCESS;
            }
        }

        try {
            // One outer transaction: if the rebuild fails, the purge rolls back
            // and the previous demo stays usable.
            DB::transaction(function () use ($institution, $purger, $seeder, $password): void {
                if ($institution !== null) {
                    $purger->purge($institution);
                }
                $seeder->seed($password);
            });
        } catch (DemoPurgeFailedException $e) {
            report($e);
            $this->error("Demo reset failed while deleting {$e->label}. No data was changed.");

            return self::FAILURE;
        } catch (DemoRefusedException $e) {
            $this->error('Demo reset refused: '.$e->getMessage().' No data was changed.');

            return self::FAILURE;
        } catch (Throwable $e) {
            report($e);
            $this->error("Demo reset failed while rebuilding the demo dataset ({$seeder->currentStep()}). No data was changed.");

            return self::FAILURE;
        }

        $rebuilt = $inventory->institution();
        $this->info('Demo reset complete.');
        if ($rebuilt !== null) {
            $this->table(['Demo data', 'Count'], $inventory->summaryRows($rebuilt));
        }

        return self::SUCCESS;
    }
}
```

````markdown
## Demo environment

A separate, fully fictional **Pharmalab Demo College** can be created on Railway staging or local Docker for client demonstrations. It never touches the local-development accounts above.

Required variables:

```env
DEMO_MODE=true
SEED_DEMO=false
DEMO_PASSWORD=<at least 12 characters>
```

- `DEMO_MODE=true` allows the demo commands to run; without it they refuse and change nothing.
- `SEED_DEMO=false` stops `docker/start.sh` from re-creating the older local-development accounts on every boot alongside the demo institution. Existing accounts are not removed automatically.
- `DEMO_PASSWORD` is the password for every demo account. It is never printed or logged.

Commands (on Railway: `railway ssh`, then run them):

```sh
php artisan demo:seed          # create anything missing; rotate demo passwords
php artisan demo:reset         # show what will be removed, confirm, then rebuild
php artisan demo:reset --force # same without the prompt (safety checks still run)
```

`demo:seed` leaves existing demo cases unchanged; use `demo:reset` to restore them after a demonstration. `demo:reset` deletes only the demo institution's data and refuses if that institution contains any account outside the demo allowlist. Deploys never seed or wipe demo data.

| Role | Email |
| --- | --- |
| Institution administrator | `admin@pharmalab-demo.test` |
| Faculty / preceptor | `faculty@pharmalab-demo.test` |
| Student (all case states) | `student1@pharmalab-demo.test` |
| Student (second progress row) | `student2@pharmalab-demo.test` |
````
